# Janus Console

The frontend control plane for the Janus API Gateway. Built with React, Vite, Tailwind CSS, and TypeScript.

## Features
- **Global Overview:** Real-time metrics on API traffic, success rates, and estimated billing.
- **My APIs:** Manage backend services and apply dynamic routing rules.
- **API Keys:** Generate and manage secure `sk-` keys to authenticate against the gateway.

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router
- Recharts (Data visualization)
